📲 Instalar en el móvil

Una vez publicada en una web HTTPS, añade este acceso a la pantalla de inicio. Es gratis y no requiere Play Store ni App Store.

Android / Samsung: Chrome ⋮ → Instalar aplicación o Añadir a pantalla de inicio. iPhone: Safari → Compartir → Añadir a pantalla de inicio.

📣 Telegram automático · 0 €

La publicación diaria está preparada para ejecutarse con GitHub Actions cuando se conecten un bot gratuito y un canal privado. Las personas invitadas reciben un aviso diario una vez publicados y verificados los precios de mañana.

En esta versión, Telegram no requiere introducir números de teléfono en la web. Los destinatarios se incorporan aceptando la invitación al canal privado. La configuración del bot no está activada todavía: hasta completar las credenciales en GitHub no saldrá ningún envío automático.

Aviso previsto tras las 20:30 (Europa/Madrid), con reintento si los datos aún no se han publicado. Las tareas programadas pueden sufrir retrasos.

🛡️ Seguridad y coste

El precio corresponde únicamente al término de energía PVPC sin impuestos, y no es el precio de todas las tarifas eléctricas. Una cifra negativa no convierte la factura total en negativa. Si los datos de la fecha solicitada faltan o fallan, la app bloquea el envío del informe de ese día. La apertura de WhatsApp usa enlaces públicos y requiere que tú confirmes «Enviar». Sin servidor de contactos, sin suscripciones y sin contratación de servicios. WhatsApp no realiza envíos automáticos. Telegram sí podrá enviar automáticamente desde GitHub Actions cuando se activen las credenciales privadas; la PWA no permanece activa de fondo. El ahorro depende de tu contrato de electricidad.

Fuentes de datos: Red Eléctrica / ESIOS, mediante EnergiAlert API o Luz por Horas JSON.
